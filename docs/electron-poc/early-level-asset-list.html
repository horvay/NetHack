Early Dungeon Asset List for Electron Tile Renderer POC

Planning pass only: image/tile assets to create for the first few NetHack dungeon levels and initial game UI, derived from NetHack source/data plus the current shim bridge renderer.

Scope assumption
Prioritize dungeon levels 1–4, character level 1–3, ordinary room/corridor levels, starting inventory/pets, and common random objects/monsters. Include a few difficulty-4/level-3+ monsters because they can appear early by generation difficulty, groups, or branches.
Renderer assumption
The shim currently streams shim_print_glyph with ASCII char, coordinates, cursor, text, and status fields. First tile pass should map glyph/char/class metadata to sprites while preserving the ASCII fallback.
Priority key
P0 required for first playable visual pass · P1 common early gameplay · P2 useful near-early/edge cases · P3 placeholder acceptable.

Traps and hidden hazards

All visible traps use trap glyphs from include/defsym.h. src/mklev.c gates random trap types by level difficulty: level <2 excludes rolling boulder and sleeping gas; level <5 excludes level teleport/spiked pit; level <6 excludes land mines; level <7 usually excludes webs; fire traps require Gehennom.

Recommended first asset batch

  1. Tileset base: floor/dark floor, wall, corridor, closed/open door, stairs up/down, unknown stone, cursor overlay.
  2. Actors: hero @, kitten, little dog, jackal, goblin, kobold, grid bug, lichen, sewer/giant rat, newt, gnome/dwarf/hobbit.
  3. Object classes: one clear tile for each object class glyph; then food ration, gold, common weapon, common armor, potion, scroll, wand.
  4. UI: status strip with HP/Pw bars, message panel styling, condition badge set, pet/friendly marker overlay.
  5. Second pass: traps, fountains/sinks/altars/graves, mold/blob/eye/spider/bat/snake variants, role-themed hero sprites.

How this list was derived

  • include/defsym.h: canonical terrain symbols, trap symbols, monster class glyphs, and object class glyphs/descriptions.
  • include/rm.h: level terrain types and flags for walls, doors, stairs, furniture, water/lava/ice, and room/corridor semantics.
  • include/trap.h and src/mklev.c: trap type enum and random trap gating by level difficulty.
  • include/monsters.h / src/monst.c: monster generation flags, frequency bits, base level, difficulty, symbol, and color. A quick extraction selected normally generated monsters with base level ≤3 or difficulty ≤4.
  • include/objects.h: object classes, probabilities, names/descriptions, and common early equipment/consumables.
  • src/role.c: roles, starting pet references, races, genders, and alignments used for player identity and status/UI.
  • electron-poc/src/renderer.js, electron-poc/src/styles.css, and electron-poc/shim-bridge/nh-shim-bridge.c: current POC consumes map glyph chars, cursor, status, and message events; asset plan targets that bridge rather than a native NetHack tile pipeline yet.
