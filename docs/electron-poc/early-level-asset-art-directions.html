NetHack Early-Level Asset Art Directions

Revised production checklist for the Electron tile-renderer POC. Every formerly grouped planning row has been broken into individual image assets, each with symbolic/iconic art direction for tile or UI production.

Scope
Dungeon levels 1–4, character levels 1–3, normal room/corridor play, early pets, common random objects, common monsters, and a small set of early edge cases.
Renderer contract
Current shim bridge streams ASCII/glyph chars, coordinates, cursor, messages, and status fields. These assets should map cleanly from glyph/class metadata while retaining ASCII fallback.
Counts
239 individual assets: Terrain and features: 32, Traps and hazards: 23, Player, pets, and identity: 25, Common early monsters: 60, Objects and inventory items: 77, UI, status, and overlays: 22.
Priority key
P0 first playable visual pass · P1 common early gameplay · P2 useful edge cases · P3 placeholder acceptable.
Art direction principle: Make tiles symbolic and iconic, not painterly. Each asset should remain legible around 16–32 px, use large silhouettes and simple color cues, and avoid realism that obscures the gameplay read.

Production sequencing

  1. Base map P0: unknown stone, floors, walls, corridors, doors, stairs, cursor, message panel, status fields, HP/Pw bars.
  2. Actor P0: hero, starting pets, first-floor animal/vermin/fungus/reptile monsters, goblin/kobold/hobbit/dwarf/gnome.
  3. Object P0: object-class icons, food/gold/corpse, common weapons, boulder/statue.
  4. Early interaction P1: traps, furniture features, role/race variants, tactical monsters, armor/tools, identified consumable and wand icons.
  5. Fallback P2/P3: special terrain, rare monsters/items, debug overlays, and trap detection markers.
